# data

Inputs and outputs for the offline tools.

- [`fixtures/synthetic`](fixtures/synthetic) is an invented 12-round fixture set, generated by [`../internal/fixturegen`](../internal/fixturegen). `fixture.json` holds the rounds, `expected.json` is the oracle, and the `rpc-*.json` files are the recorded exchanges. It is not mainnet data and the README says so.
- `fixtures/live-{block}` is where `go run ./cmd/verify -capture` writes a real recorded round. No captured set is committed.
- [`replay/plan.example.yaml`](replay/plan.example.yaml) is the template for `cmd/replay`. Copy it to `plan.yaml` and fill in block heights and token ids.

Probe output and replay results are git-ignored. The committed fixture set is the one the judge check uses.
